Simmer & Serve — a tiny kitchen rush. You are the only chef on the lunch shift: take orders off the board, chop and grill the ingredients, plate each dish and serve it before its ticket walks out. Orders pile up, patience runs thin, and the last thirty seconds are a full rush.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests — every file the game loads lives under `game/`.

## How to play

- Move — WASD or arrow keys
- Use a station — E (hold E at the chopping board to chop)
- Click a station to use it · P — pause · M — mute · Enter — start

Recipes: Sunny Burger (bun + grilled patty + chopped lettuce + chopped tomato), Garden Salad (chopped lettuce + tomato + onion), Cheesy Melt (bun + grilled patty + cheese), and the Tower Stack for the brave. Serve fast for a tip, chain serves for a combo, and don't leave a patty on the grill — it burns.
